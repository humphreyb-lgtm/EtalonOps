# MRF PDF foundations v37

Adds job delivery contact name/phone, purchasing agent name/email, receiving hours and job delivery instructions to Jobs administration. Purchasing agent is presently a job contact assignment; it does not grant purchasing permissions or enable approval routing. The builder adds Work Area, Default Task Code (16 characters), Packaging Method (editable text, initially Standard), Special Packaging Instructions, Delivery Instructions and Purchasing Notes in aligned compact fields. Assigned-job address/contact defaults are visible in the builder. Draft save/load and revision creation retain MRF form data.

Migration 13 adds drafts.form_json and a tenant-scoped versioned PDF template-settings record. Existing migration checksums are untouched; restricted runtime grants include pdf_templates. Submission snapshots freeze the current job details, company name and authenticated preparer contact details alongside MRF instructions. The selected requested-for foreman remains separate. Later user/job edits do not change recorded submission facts. CSV exports include default, printed and effective task codes. A blank item code inherits the header default; a matching code is printed blank; a different override is printed.

A real AcroForm PDF generator (pdf-lib) provides editable text widgets and No Substitutions checkboxes, quantity plus UOM in one cell, unchanged product descriptions, manufacturer/part wording, default/override task codes, notes, multipage item rows, repeated headings, page numbers and available approved uploaded photos. The authenticated owner can Download draft PDF from submission review or Download fillable PDF from submitted details. Draft output is marked draft and does not submit. PDF edits are offline edits to the file and do not update the database. Standard-font output currently targets English trade data; a full Unicode-font/brand-logo library is future designer work. External image URLs remain available in app views; this initial PDF embeds approved uploaded files from private storage.

Administration > PDF templates provides starter settings for title, company heading, Letter/A4, color, field font and description width, plus a fillable sample download. This is a settings editor, not yet the drag-and-drop designer. One active settings record per tenant is supported, with optimistic edit version and audit event. Export uses saved submission data and the current layout settings; freezing layout versions on release and multiple company/job-specific templates remain future work.

Recommended next template phase: a browser designer for reusable header, contact, instruction, repeating item-table and footer blocks with data bindings, alignment guides, live preview and draft/publish template versions. Excel import is optional reference/conversion assistance, not the layout engine. Generated PDF fields must stay unflattened and pass AcroForm round-trip checks. Templates do not require external PDF-authoring software.

Install the cumulative source ZIP and run scripts/update-cloud-app.sh. It installs the PDF dependency and applies migration 13. Health reports pdf-foundation-v37. No new Azure resource or AI call is required. Validate job contacts in Users > Jobs, request instructions in the builder, draft and submitted PDF downloads, PDF template settings, and a saved-draft/revision round trip.
