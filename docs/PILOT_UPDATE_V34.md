# Grouped catalog review v34

Catalog import review defaults to one row per generic material and its related manufacturer products, images and search phrases. Items sharing a material are reviewed together, so shared specifications are never deleted while a hidden sibling product is left behind. Select this page / all pages select supporting unpublished records as a unit. Search and status filters operate on whole groups. One approval publishes the selected groups; grouped publication is disabled if the publication plan holds any selected record. Deleting a selected group removes its unpublished supporting records only; published catalog data remains intact. Advanced individual-record mode preserves existing repair and partial-publication workflows.

The dense row provides inline description, manufacturer, part, image URL, unit and defining specifications. Search phrases and additional details are collapsed. Duplicate/conflict badges remain prominent and repeated material-dependent warnings collapse to the underlying issue. Known catalog-section, series and country metadata from new prepared imports are stored as manufacturer product details rather than generic material identity. Older blocked imports offer Organize manufacturer details, then Save inline changes, to move these known fields without another upload. This does not automatically approve or publish anything.
