# v48: Manual MRF item review and Global Design

Manual entries remain MRF-only. Adding a line immediately records an administrator inbox event; saving a draft provides a transactional fallback. Reports retain original search wording, final manual wording, quantity/unit, job, requester, MRF/line identity and time. Retries and saves reuse a scoped event; identical line IDs from different owners do not block independent drafts. Submitted-revision copies retain the original report context rather than silently moving it to a different MRF.

Administration shows a pending-count badge (refreshes on focus and every 30 seconds) and Manual Item Review. Filter by job, status or wording, see repeated wording, review an existing material, optionally approve a safe translation, ignore or reopen. Creating a material uses the existing inline Materials editor and its review/duplicate checks. The report resolves after that save; if resolution fails it remains pending and the new material can be linked on retry. Catalog links never rewrite the original MRF line. Known conflicting or incomplete specifications block phrase learning. No external email, AI call or paid search is sent. Reports start with this release; an older saved manual line is captured when its draft is next saved, not through a bulk historic backfill.

Global Design provides 11 reusable styles: Heading 1/2/3, Body, Form label, Form field, Button, Primary button, Supporting text, Table heading and Table cell. Each controls a safe font family, size, weight, color, line height and horizontal/vertical padding. Dense defaults reduce form padding. Single-line fields and buttons share calculated height. Unsaved changes affect only the live preview; Save applies the settings to this page and other pages on focus/within a minute. Preview dense defaults + Save restores defaults. The public sign-in page reads only presentation settings from a fixed-tenant endpoint; writes require administrator access and version checks. PDF/document canvas typography remains independent.

Migrations 15/16 add the inbox, presentation settings and explicit source-line tracking. Existing catalog, images and MRFs are retained. SQL runtime grants include only the new application tables, following the existing deployment mechanism. Deploy with scripts/update-cloud-app.sh. No catalog reimport is needed. Expected health release: manual-review-design-v48.

Validation: 162 server tests, 66 SQL integration tests, five feature/search browser tests and six existing Materials/header browser regressions passed. The browser flow covers immediate manual entry reporting, approved linking, reviewed duplicate-aware material creation, isolated design preview, persistence into another browser page, and FA/MA search retention. Deployment ZIP membership was checked for every new runtime module and both additive migrations.
