# Catalog match markers v22

Unpublished import review automatically checks existing canonical materials and manufacturer parts when an import is opened, uploaded or saved. Bold amber MATERIAL ALREADY EXISTS / PRODUCT ALREADY EXISTS badges, row highlights and a summary make matches stand out before selection. Red EXISTING PRODUCT — REVIEW / CATALOG CONFLICT markers identify conflicting facts, retired products or unresolved mappings. Hover a badge for its reason. Counts refer to material/product review rows, not unique products.

A new manufacturer product for a known generic item marks only the material as existing. Draft edits hide stale markers until Save inline changes refreshes them. Checks are tenant scoped and read-only. Publication approval and existing conflict checks remain authoritative; markers do not publish or overwrite facts. Reopen or refresh the publication check to see subsequent catalog changes. No AI or Bing call is made.
