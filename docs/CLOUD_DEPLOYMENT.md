## Owner execution

Use the approved Azure Standard account in an ephemeral Bash Cloud Shell. Download `EtalonOps-westus3-deploy.zip` from the repository's `preview-download` branch, then use Cloud Shell **Manage files → Upload**. The package contains source/instructions only, with no credentials or local database.

```bash
unzip EtalonOps-westus3-deploy.zip -d etalonops-westus3
cd etalonops-westus3
bash scripts/deploy-cloud.sh westus3
```

Review scripts before execution. The script verifies the exact subscription, Node 24 runtime listing, B1 selected-region listing and Entra setup, builds and tests source, preserves the owned group (creating it only if absent), validates the template, and checks the ARM What-If report for deletions, uncertain changes and mutations outside the pilot template, then deploys within approved scope. It refuses to adopt an existing unmarked group. Its generated names use a deterministic subscription hash; global name/capacity conflicts surface as deployment errors rather than overwriting unrelated resources.

If Cloud Shell lacks Node 24, the helper downloads official Node 24.19.0 into its own local directory, verifies its published SHA-256 before extraction and uses it without root access. Download/verification failures stop before resource creation. Do not change engine constraints or bypass certificate verification. Do not enter a database password or GitHub token. The dependency install/build uses this source ZIP, avoiding private-repository credentials.

No secrets are written by the scripts. Azure CLI's existing Cloud Shell credential cache remains outside the package. SQL access tokens are passed from CLI stdout directly into Node's driver and never printed/saved. `.runtime/azure-deployment.json` contains non-secret resource/application IDs and must be downloaded before an ephemeral Cloud Shell closes. Preserve this file to resume. If the ephemeral session has already lost it, exact-manifest recovery can reconstruct the non-secret identity identifiers; it does not recover cloud credentials. Other runtime files include manifests, ARM preview and app ZIP; do not upload unrelated Cloud Shell credential caches.
