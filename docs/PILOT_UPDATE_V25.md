# Editable material display descriptions v25

Administration → Materials now has an inline Description text area for each material and the New material row. Initial descriptions come from the existing generated wording. Edit directly, click Review changes, approve the preview and Save material. Use generated description resets custom wording to the current generated description. Blank custom descriptions are rejected; generated mode is the explicit reset. Display descriptions may contain up to 2,000 characters.

The display label is separate from the canonical specification identity. A wording-only change updates the same material record with a revision entry. Manufacturer product IDs/relationships, images, translations, aliases, priority, job rules and verification status remain unchanged. Existing saved MRFs retain their original candidate and line text; new searches use the current display description. Existing generated-description aliases remain available to search. Reimporting the same canonical material reuses it without replacing an administrator's custom wording.

Changing specification fields still follows the existing reviewed correction/replacement rules. Metadata/evidence edits retain an existing custom description. A defining-specification replacement uses freshly generated text unless custom wording is explicitly entered in that same review, avoiding silently carrying obsolete size claims onto a different specification. Review shows the actual resulting description and impact. This is a wording editor, not a parser that changes specifications based on text.

Description edits and reset are admin-only, tenant scoped and protected by row and preview hashes. Unchanged numeric specification values retain their original types during editing, including measurements and other numeric fields such as rollLengthFt. No new migration, Azure resource or paid AI call is required for this change; the update remains cumulative through migration 9.
