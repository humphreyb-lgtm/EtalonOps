# Website appearance and content

The earlier appearance-only v49 editor has been superseded by the full CMS in release `cms-suite-v49`.

Use **Administration → Content management** or `/cms`. The CMS manages existing pages and modals, new pages, navigation, nested modules, reusable content, media, responsive/state styling and scoped CSS. See [CONTENT_MANAGEMENT.md](CONTENT_MANAGEMENT.md).

Existing saved global text and appearance values remain compatible. The new CMS adds granular overrides and its protected editor is excluded from published website styling. Use `/cms?cmsRecovery=1` for design recovery; normal administrator authentication is required.
