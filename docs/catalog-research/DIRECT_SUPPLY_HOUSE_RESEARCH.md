## Direct-first workflow

1. Check the existing source register for the family before visiting any site. Reuse verified catalog/PDF URLs and image links. Do not search again for every size.
2. Open a known product, family, category or catalog link first. Otherwise enter through a listed supplier site and browse its category navigation. Use that site's own search when navigation does not locate the family.
3. Prefer supplier-linked manufacturer datasheets for exact size, schedule, angle, centerline radius, connection type, stock length and commercial availability. A supplier's own specification table can also be evidence. Cross-check conflicts; do not infer missing values from titles, photos or adjacent sizes.
4. Read a family table once and record every explicitly supported configuration from it, with its page/table locator. Do not generate unsupported size/radius combinations. Keep candidate, confirmed and unresolved configurations distinct.
5. Build a reusable photo library by visible physical type. Copy an actual direct HTTPS image URL from the product gallery, img/srcset/lazy-load data or structured image metadata. A page, PDF or image-search results URL is not an image URL. Open the image and check what it depicts before calling it verified.
6. Reuse the same verified photo URL for visually equivalent materials, including sizes of straight conduit or matching 90-degree long-radius sweeps. Use separate photos for visibly different angles, standard versus long-radius bends, male/female fittings, center-stop versus repair couplings, box/body types, spacer configurations, and one-piece/two-piece expansion fittings. Do not use a universal photo for unrelated materials.
7. Put Image URL on each applicable final Materials row. In Notes record the image source page and why it is representative. Keep specification evidence separate from photo evidence. Missing photos remain blank with a clear unresolved note; never invent URLs. Existing uploaded/internal images must not be overwritten and retain display priority.
8. Record successful links and observations in the source register. Keep a session cache so one family source and representative image can serve multiple verified rows. Revisit only if stale, conflicting or inaccessible; do not store credentials, access tokens, signed/private links or customer pricing.
9. If access is blocked, record the host and failure once, then try another supplier. Do not make repeated requests for each material on a blocked host or bypass access controls.
10. Use general web search only after accessible direct suppliers and their linked literature fail. Record the reason. Do not invoke Azure AI or paid Bing discovery for this workflow. Direct browsing is a cost-control preference, not a claim that a ChatGPT session uses no account allowance.

## Evidence record

For each verified configuration keep: material family, exact physical configuration, specification URL, page/table locator, supplier/source, verification notes/date, direct photo URL, photo source page, reusable image group, and photo verification status. These are research fields; map only supported fields into the v44 Materials sheet. Family Reference and the importer's header names remain authoritative.
