# Material workbook and family definitions — v44

Administration → Materials now downloads current/blank materials workbooks and checks a completed workbook before applying changes. One editable Materials sheet holds material specifications, phrases and representative image URLs. Instructions and Family Reference are guidance sheets, never imported data.

Existing keys update the same material, blank keys add, unchanged and duplicate configurations skip. Blank cells preserve data; [CLEAR] clears optional scalar fields. New records and URL image changes enter the existing publication review. Invalid or unconfirmed configurations must be resolved or removed before applying. Missing evidence prevents confirmed new family imports. Physical changes on materials with manufacturer products require the existing reviewed correction workflow; description edits preserve relationships and verification. Search phrase changes add phrases without deleting existing legitimate phrases.

31 initial family definitions supply required specifications, browsing groups and consistent generated description patterns. They use existing JSON specification storage; no database migration, material renumbering, or manufacturer-data import is required. Admin family filters show relevant structured fields. Unknown families must be added in a future definition update; custom categories and existing material workflows continue to work.

Search constraints reject conflicting explicit bend angles/radii, adapter gender, repair/center-stop coupling types, reducer sizes and spacer compatibility, even when a learned phrase matches. Existing size/schedule safeguards remain.

Generic images are URLs per material, with reuse across visually matching types. New approved generic URLs replace older approved generic URL references for that material; uploaded images retain display priority. Existing manufacturer images are unaffected. References remain in history.

No paid AI/Bing call is made by workbook operations. No new Azure resource is needed. The downloadable initial workbook uses the user's October 21 supplied snapshot (47 active materials / 425 active phrases); it is not a new authenticated production export.
