# Compact material rows v26

Administration → Materials uses a wide compact layout matching the requested image/description + field grid design. Image and editable description stay on the left; up to six primary specification fields, category and unit share a four-column grid (two rows for conduit/box). More and Review changes stay at the right. Status/manufacturer count remains below the description. Redundant visible table headers are removed while accessible headers and input labels remain.

Additional specification fields beyond the first six, source/evidence notes, image management and Use generated description are under More. All existing values are retained and remain editable. Valid unit choices are unchanged. The New material row uses the same layout. Materials uses the available desktop dialog width; narrow screens scroll the table horizontally. Other administration sections retain their existing width.

This is a presentation update. Material identity, description editing, paging, filters, category management and publication behavior remain unchanged. No new migration, resource or paid AI call is introduced.
