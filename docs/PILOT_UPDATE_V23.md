# Material-only inline table v23

Administration → Materials is a compact paginated table of generic materials. Existing rows are immediately editable. The blue New material row uses the same category, unit and defining-specification fields. Manufacturer, part number and translations are not required. General materials use Type / name and Defining specifications. Conduit, telescoping bracket and box categories expose their defining fields. Inch fields accept exact fractions; decimal values are formatted as trade fractions where exact.

Click Add material / Review changes to review within the table, select the review checkbox and Save material. New entries become active provisional catalog materials and are searchable after this explicit save. Canonical duplicates reuse their existing material; no manufacturers or products are invented. More contains optional manual source URL, evidence notes, change reason, additional specification fields and Generic image management. Sources remain mandatory for AI-origin materials; blank manual sources are administrator declarations, not independently verified evidence.

Defining specification/unit changes use the existing correction/replacement workflow, retain old material records and saved MRF snapshots, and show related product/image/rule impact before saving. Existing relationships remain with the old material and require separate review. Uploaded-image impact counts do not include external image references. A manual-entry/edit reason is supplied automatically and can be customized under More. Stable keys are generated automatically. Material key entry, manufacturer setup and JSON are not required.

Rows edited concurrently are rejected using a snapshot hash. Discard row resets local changes; Refresh materials loads the current catalog. Paging/filtering is disabled while rows are dirty, and saving a row preserves other rows' pending edits. Tables scroll horizontally on narrow screens. All table endpoints require administrator access and are tenant scoped. No migrations, new resources or AI requests are required.
