EtalonOps Excel catalog template and combined update v10

For catalog preparation: download EtalonOps-catalog-template.xlsx using Download raw file and open it in Excel. It is a blank native Excel workbook with ordinary columns and separate parts/manufacturer/translation/image sheets. One record per row, one phrase per translation row; no JSON cells. Keep the master XLSX and export populated data sheets as CSV UTF-8 (Comma delimited) for import. Direct XLSX upload is not supported.
The starter ZIP includes the workbook, separate flat CSV templates, fictional examples and preparation instructions. FICTIONAL-EXAMPLE files are syntax examples, not real launch stock.

Install EtalonOps-pilot-update-v10.zip on the existing pilot before importing the new flat CSVs. It includes all earlier updates and maintains legacy JSON batch compatibility. No new service, subscription, schema migration, application dependency or paid AI is added. Azure installation remains pending.
